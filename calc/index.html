    What it understands

    • Arithmetic with + - * / % ^ and brackets
    • Assignment: x = 4, then x^2
    • ans holds the previous result
    • Functions: sin, cos, tan, asin, acos, atan, sqrt, cbrt, abs, ln, log, log2, exp, floor, ceil, round, sign, min, max, gcd, lcm, fact
    • Constants: pi, e, phi, c (light), g0 (gravity)
    • Units: 3 km + 250 m in m, 90 min in h
    • Percentages: 200 + 15%
    • Bases: 0x1f, 0b1011, and 255 in hex
